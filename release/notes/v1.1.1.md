# PAN Builder v1.1.1

27 November 2026. This update explicitly sets session timeout inheritance for every generated service object.

## Changed

- TCP services now include `protocol tcp override no` immediately after the port command.
- UDP services now include `protocol udp override no` immediately after the port command.
- The protocol comes from the service's selected protocol, including custom names, port ranges, saved workspaces, and matrix imports.
- The commands appear in the preview, clipboard output, and downloaded configuration, with the selected firewall or Panorama scope.

Example:

```text
set service TCP-1024-65535 protocol tcp port 1024-65535
set service TCP-1024-65535 protocol tcp override no
set service UDP-53 protocol udp port 53
set service UDP-53 protocol udp override no
```

`override no` explicitly selects inherited application timeouts. Applying these commands to an existing service changes its timeout configuration to inheritance; custom service timeouts are not preserved. See the [PAN-OS CLI reference](https://docs.paloaltonetworks.com/ngfw/pan-os-cli-quick-start/cli-command-hierarchy/pan-os-11-2-configure-cli-command-hierarchy) and [service settings](https://docs.paloaltonetworks.com/ngfw/help/11-1/objects/objects-services).

## Install or update

Close the PAN Builder launcher, then run **Install-PAN-Builder.exe** from this release or the **PaloAltoCommandGenerator-1.1.1-Windows.zip** download. Existing desktop and Start menu shortcuts continue to work. Saved browser workspaces are preserved and use the updated command generation when reopened.
