# PAN Builder v1.1.0

First GitHub release, 26 November 2026. PAN Builder creates Palo Alto PAN-OS address, service, and group commands locally on Windows.

## Download and install

Download **Install-PAN-Builder.exe**, or extract **PaloAltoCommandGenerator-1.1.0-Windows.zip** and run the installer. Setup creates desktop and Start menu shortcuts. Use the **PAN Builder** shortcut for subsequent launches and keep the launcher open while working in your browser.

The installer contains the complete application. No separate application EXE, Node.js, or internet connection is needed for normal use.

## Included

- Address objects for IPv4, IPv6, networks, ranges, and FQDNs.
- TCP/UDP service objects, address groups, and service groups.
- Excel and CSV firewall matrix import with keyword filters, column mapping, validation, and row corrections.
- Command preview, copy/download, workspace import/export, and local browser storage.
- Light/dark themes and bundled Oswald font.
- Address naming such as `NET_10.202.52.0_23`.
- Per-user installation, shortcut repair, and uninstall support.
- An organized repository with development files under `app/` and the installer at the top level.

## Verification

The Windows build, all 36 unit tests, offline browser workflows, installation, shortcut creation/repair, and uninstall checks passed. Release assets include `SHA256SUMS.txt` with checksums for the installer, ZIP, guide, and notices; the ZIP also contains its own checksum file.

## Requirements and data

Use Windows 10/11 with .NET Framework 4.6 or newer and a current browser. The build is unsigned. Matrix files are processed locally. The app generates commands for you to review and apply; it does not connect to or configure your firewall. Export your workspace to back it up or move it to another browser or computer.
